# Defense Factory v0.1 — proposta
Núcleo puro de triagem defensiva, sem rede, execução de comandos, credenciais ou escrita em produção. Não concede autoridade. O chamador autenticado deve obter o escopo do Ethics Engine, verificar parada de emergência e autorização antes de cada operação externa. Escopo vazio nega tudo. Achados são alegações não verificadas; referências opacas não são evidência validada. Não inserir segredos ou dados pessoais. Correções futuras exigem branch isolada, revisão independente e autorização vinculada ao commit. Não habilitar scanners até integração e testes de autorização. A política de divulgação segue SECURITY.md.
