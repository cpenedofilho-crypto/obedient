# OSIL — experimental synthetic core
Status: prototype, not production integrated. Pure TypeScript functions, no network, database, tools, credentials or personal data. Fixed seed and bounded scenario count (10,000). Models hypothetical mission failures and compares single attempt with bounded retry on identical scenarios. Synthetic metrics are not real-world evidence. The generator is non-cryptographic. No automatic promotion or memory writes. No new workspace manifest yet; source is covered by existing TypeScript and test globs. Future integration must reuse Ethics Engine, Mission Engine and Memory, with explicit grants, cancellation, durable state and audit. Threat model: unbounded input, policy injection, accidental external effects and misleading synthetic metrics. Mitigations: strict numeric bounds, closed policy vocabulary, pure functions and synthetic labels. Tests cover determinism, bounds and accounting. Full CI and integration review required before promotion. No migration or deployment required for this prototype.
